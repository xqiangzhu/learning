# 12. 供应商独立直连矩阵、私有编码多层映射、到检结算与分院下线容灾 (Supplier Direct Integration Matrix, Multi-tier Packet Mapping & Settlement)

体检供应商中台确立“**全矩阵独立 API 直连对接**”、“**核心三层私有编码映射与前置拦截**”、“**即时同步落标预约失败（07）**”、“**以‘已到检(04)’为供应商法定结算里程碑**”以及“**分院停业降级线下客服改约容灾**”架构机制。

## 背景与权衡

体检供应链是平台商业运转与医疗履约的命脉，涉及全国数十家民营体检连锁与各级公立医院：
1. **供应商异构协议与中介依赖**：市面存在聚合中介服务商，但中介层增加了故障环节与数据延迟；平台选择与各品牌直连以保障对排期与履约数据的端到端掌控力；
2. **套餐编码的多级映射断裂**：平台标准体检套餐、企业定制包与供应商机构内部的私有项目编码口径各异；若映射存在盲区，会导致机构现场开单错误或漏检；
3. **API 锁单超卖与重试复杂性**：名额争抢失败时，若引入长时间异步重试队列，会导致员工处于“悬空未决”状态，且极易引发并发下的幽灵占容；
4. **采购结算的法定权责界限**：结算若定在出报告（05），当出现漏出报告或体检中心合规延期时会引发供应商催款纠纷；但若定在预约成功（02），爽约又会导致平台资金损失；
5. **分院停业对在途订单的冲击**：分院因装修改造或不可抗力临时停业时，若系统直接粗暴退单，会严重损害企业员工的就检体验。

## 架构决策

- **全矩阵品牌独立 API 直连（Direct Independent Integration, Zero-Aggregator）**：
  - 平台与爱康国宾（`aikang`）、美年大健康（`meinian`）、瑞慈（`ruici`）、慈铭（`ciming`）、嘉会医疗（`jiahui`）、中科体检（`zhongke`）等所有外部民营品牌**全部采用一对一独立 API 直连**；
  - 彻底规避第三方中介聚合平台的单点故障与链路黑盒，由平台独立维护各供应商的报文协议、鉴权与接口防腐层（`SupplierPort`）。

- **核心三层编码映射与前置阻断门禁（Multi-Tier Packet Mapping & Pre-Filter）**：
  - **三层映射体系**：由下游核心系统（HMSCS）统筹维护“**平台标准套餐编码 ➔ 内部供应商套餐编码 ➔ 机构私有项目编码**”的强类型映射字典；
  - **前置排期过滤**：前端在用户查询分院排期阶段即对映射关系进行有效性校验；若目标分院缺失任一加项包或主套餐的私有映射，该分院直接前置置灰或过滤；
  - **转换硬校验报错**：预约阶段（`transformPacketCodeOffline`）执行严格硬校验；若发现未映射编码，系统立即中断抛出明确异常，坚决阻止脏数据流入外部机构。

- **即时同步落标预约失败策略（Synchronous Failure Policy）**：
  - 调用供应商直连 API 锁单若遭遇网络超时、名额已满或接口校验拒绝，系统**不引入悬空等待的异步定时重试**；
  - 预约状态**直接同步落标为 `预约失败 (07)`**，并在前端界面即时向员工反馈具体错误原因，释放用户选择权，由员工自主即时重选门店或时段。

- **以“已到检 (04)”为法定采购结算里程碑（Check-in Statutory Settlement Milestone）**：
  - 平台与供应商的采购结算对账**严格以“已到检 (04)”为法定基准节点**；
  - 持有人一旦在分院现场核销到检，即代表供应商医疗采血、试剂耗材与医护排班成本已实际发生；后续报告出具与异常解读属于增值交付，不阻碍基础检查成本的账期核销与请款。

- **分院停业降级线下客服改约容灾（Store Suspension Graceful Downgrade）**：
  - 当某分院因故停用或下线时，系统坚决禁止批量自动作废或取消在途预约单；
  - **降级为线下模式**：系统自动将该分院项下未到检的有效预约单调整为“线下协调模式”；
  - **人工协调改约**：由客服在 MIS 后台调取受影响名单，通过电话主动外呼与员工沟通，协助员工协调转移并重新预约至同品牌临近分院。

- **分院口碑评价参考体系（Voluntary Store Evaluation）**：
  - 员工体检完成后，系统开放针对环境、服务、医生等多维评分与标签评价入口，属于**完全自愿参与**；
  - 评分与评价内容仅作为前端其他员工选店排期的决策口碑参考，不直接与供应商月度考核扣款挂钩。

## 效果与影响

- **链路透明可控**：直连无中介架构赋予了平台对全国数千家分院排期与履约状态的毫秒级感知力；
- **排期零脏单**：三层映射与前置排期拦截彻底杜绝了因编码缺失导致的机构端拒单；
- **权责财务清晰**：以“已到检”为结算基准消除了出报告周期的财务结算摩擦；
- **服务温度保全**：分院停业转线下外呼改约机制守住了招商信诺高端企业福利服务的口碑底线。
