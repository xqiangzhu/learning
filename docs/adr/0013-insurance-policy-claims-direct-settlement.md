# 13. 保单赠送体检商保直赔、理赔前置鉴权与核心SFTP归档 (Insurance Policy Bundled Checkup, Direct Claims Settlement & Core SFTP Archival)

体检平台针对保险衍生体检业务确立“**保单赠送体检商保直赔（Direct Claims Settlement）**”、“**团险核心同步与前置理赔资料门禁**”、“**手写电子签名动态盖章合成（mergeClaimsData）**”以及“**异步专线 SFTP 推送至保险核心结案**”架构机制。

## 背景与权衡

招商信诺作为专业健康险公司，企业客户常将体检作为团险/个险保单的核心健康管理附加增值权益：
1. **保险精算与合规审计要求**：保单项下赠送的体检成本最终需从保险保单责任准备金中进行理赔结案与核销。监管及精算合规严格要求具备持有人身份证明、手写授权与具备法律效力的《理赔申请书》影像凭据；
2. **直赔免付 vs 事后繁琐报销**：若让员工先自费垫付体检再走传统保险理赔，流程极其冗长且满意度低下；平台采用“直赔免付（Direct Settlement）”，员工享受 0 元体检，后台自动化完成保单理赔核销；
3. **两类异构保单客群**：既存在由团险核心同步而来的企业大客户团险保单（EWP），又存在个人散客购买的个险健康保单（SWP），两者的保单归属与理赔凭证结构需要清晰隔离。

## 架构决策

- **保单赠送体检商保直赔模型（Direct Claims Settlement）**：
  - 体检权益由保单产品赋权（非纯现金采购福利）；
  - 持有人在体检平台享受全额直赔免付，无需垫付资金，后台理赔单据与就检核销自动冲抵保单理赔责任额度。

- **团单理赔标识与前置资料采集门禁（Claims Gate on Equity Access）**：
  - **核心保单同步**：企业团单由**团险核心系统（Group Insurance Core）**自动同步至 HMSC 核心，配置生成企业体检方案与团单号（`teamOrderCode`）；
  - **理赔申请开关（Claims Application Enabled Flag）**：团单维度配置“是否理赔申请”标识；
  - **前置资料门禁**：若团单开启理赔标识，员工在指定入口查阅并使用该体检权益时，系统强制激活理赔资料门禁；员工必须在线完成**身份证正反面 OCR 上传**与**实时手写电子签名（Electric Sign）**，否则阻断后续体检预约流程。

- **理赔资料动态盖章与法律凭证合成（mergeClaimsData）**：
  - 系统捕获用户手写签名轨迹图片（`electricSignImageUrl`）与身份证 OCR 影像；
  - 服务端调用 `mergeClaimsData`，将持有人身份信息、保单号、体检项目与手写签名动态渲染压印至标准 PDF 模板，生成符合司法与保险监管规范的《体检理赔申请授权书 PDF》。

- **异步专线 SFTP 推送至保险核心（Async SFTP Core Pipeline）**：
  - **事件驱动解耦**：资料合成后触发 `ClaimsDataEvent`（`PUSH_CLAIMS_DATA_TO_HMC`）；
  - **安全传输**：监听器（`ClaimsDataListener`）通过专线网络连接至 211 核心内部 SFTP 服务器（`hmsc.ftp.server.host`），将签名文件、身份证影像与理赔 PDF 自动分发上传至指定路径（`ewp/electricSign/yyyyMMdd/`）；
  - **双客群分立存储**：
    - 企业团单员工归档至 `EwpClaimsDataBean`；
    - 个人个险散客归档至 `EwpSwpClaimsDataBean`。

## 效果与影响

- **极致用户体验**：直赔免付模式让保单客户享受无感顺畅的体检履约，彻底告别垫资与纸质发票报销；
- **全链路合规闭环**：手写电子签名 + OCR 身份证 + 动态合成 PDF 形成了不可篡改的法律证据链，满足国家商保稽核与精算审计要求；
- **核心数据打通**：通过团险同步与 SFTP 专线推送，完成了体检健康服务中台与保险核心理赔系统的无缝账务结案闭环。
