# 2. 预约取消与退款的双轨联动机制 (Dual-Path Refund & Appointment Cancellation)

系统支持两种退款与取消预约路径：既支持用户“先独立取消预约、后续再退款”，也支持“直接申请退款并由系统自动级联取消预约单”，确保外部机构档期释放与退款闭环。

## 背景与权衡

体检预约成功后，主套餐与加项包已同步至外部体检供应商（爱康、美年、瑞慈、中科等）锁定分院排期。

在退订诉求发生时，用户的心理模型存在两种不同分支：
1. **仅调整就检计划**：因近期有事无法到检，仅想取消预约释放名额，保留体检资格后续重新预约；
2. **彻底放弃体检并退款**：不想再去体检，期望一键退单退钱，不希望被繁琐的两步操作打断。

## 架构决策

系统提供双轨协同的退单退款联动架构：

- **路径一：分步独立操作（先取消预约，后申请退款）**
  - 用户触发“取消预约”：仅调用取消预约接口释放分院排期，预约单置为 `03-已取消`；
  - 订单状态维持 `02-已支付/待预约`，体检权益完好保留，用户可随时重新预约；
  - 若用户后续决定彻底放弃，可再次发起“申请退款”，进入退款结算流程。

- **路径二：一键级联操作（直接申请退款，系统自动级联取消预约）**
  - 用户直接点击“申请退款”：系统首先检测关联预约单状态；
  - 若预约单尚未取消（非 `03-已取消` / `07-预约失败`），系统底层**自动编排并触发 `cancelOrderAppoint` 释放外部机构排期**；
  - 预约取消成功后，系统即刻推进主订单退款（置为 `06-退款中` / `07-退款成功`），预约单与主订单一键同步闭环。
