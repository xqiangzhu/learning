# 体检系统升级 V2 · 领域术语表 PPT

把 `CONTEXT.md`（体检系统升级V2 领域术语表）转成可直接用于评审的演示文稿。
**一套内容模型 → 两种产物**：`.pptx`（交付物）与 `index.html`（网页速览 / 可打印成 PDF 讲义）。

---

## 1. 产物

| 文件 | 说明 |
|---|---|
| `slides/体检系统升级V2-领域术语与切流架构.pptx` | 23 页 16:9 演示文稿，含每页**演讲者备注** |
| `slides/index.html` | 单文件网页速览版，← → 翻页，`Ctrl/Cmd+P` 可打印为 PDF |

> `slides/` 是渲染产物目录（仓库根 `preview/` 同理）。目录名刻意避开 `dist/ build/ out/`，
> 那几个名字会被工作区快照忽略、不会持久化。

## 2. 重新生成

```bash
python3 -m venv /tmp/venv-pptx && /tmp/venv-pptx/bin/pip install python-pptx
/tmp/venv-pptx/bin/python build.py          # 生成 pptx + html，并打印版面自检报告
/tmp/venv-pptx/bin/python build.py --quiet  # 只在自检不通过时返回非 0
```

`build.py` 退出码非 0 表示自检失败（文字溢出或形状越界），CI 里可以直接当门禁用。

## 3. 目录结构

| 文件 | 职责 |
|---|---|
| `deck_content.py` | **唯一事实来源**：14 个术语的文案、配色/字体规范、拓扑图节点与连线坐标 |

## 6. 版面自检是怎么做的

沙箱里没有 PowerPoint / LibreOffice，无法渲染截图，所以用两道程序化检查代替肉眼验收：

- **文字溢出**：按 em 宽度模型（全角 1.0em、大写 0.70em、数字 0.56em、小写 0.52em）
  估算每个文本框的行数与高度，和预留高度比对；表格单元格同样参与（PowerPoint 会按内容
  自动撑高行）。当前 403 个文本块 **0 溢出**。
- **形状越界**：重新打开生成的 pptx，检查所有形状是否落在 13.333 × 7.5 in 画布内；
  封面/章节页有意出血的装饰圆环以 `deco-*` 命名并跳过。当前 **0 越界**。

字体统一写入 `a:latin` + `a:ea`（Microsoft YaHei），避免中文在部分环境下回退成宋体；
符号只用雅黑覆盖良好的 `· ● ▪ □ ■ × → ← ↔ ①②③`，不用 `⇄ ⚡` 这类会变方框的字符
（与仓库根 `README.md` 的画图约定一致）。
