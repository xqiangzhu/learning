## PPT 结构（36 页）

- **P01–P02** 封面 · 三层文档体系全景导航（名词解释/实体/流程/前端/集成五卡索引）
- **P03–P12** 统一语言·名词解释：59 词条 / 9 组（权益与交易、机构门店与预约、履约规则与边界、报告同步与档案、解读增值服务、购物车与合并结算、积分与福利结算、套餐与项目模型、健康商城与卡券），词条卡 = 标准定义 + 避免叫法
- **P13–P15** 领域实体全景：29 实体清单（7 大限界上下文）、核心聚合根与业务不变量、领域建模规范与 ToB 免密动态赋权
- **P16–P22** 核心领域流程：端到端主流程、上游配置与 4 路权益发放、智能选检与两阶段积分结算、预约履约与异常变更、双轨到检与报告解读、Benefit/Order/Appointment 三态状态机、体检代报销与积分报销
- **P23–P27** 前端基线：前端业务名词与口径对齐（4 处口径差异 + UI/代码↔领域术语对照）、员工体检五大页面主线（隐式上下文）、家属体检与优惠套餐双入口、报销双通道与隐藏约束、前后端状态码字典
- **P28–P36** 系统集成：8 大下游拓扑、7 张集成时序图（HMC 同步 / 积分支付两阶段 / 17+ 直连供应商 / TBDS 推荐 / 211 保险直赔 / 报告 OCR 与小诺 AI 免登 / 报销财务）、接口契约总表
