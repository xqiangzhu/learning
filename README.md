## PPT 结构（22 页）

- **P01–P02** 封面 · 三层文档体系全景导航
- **P03–P09** 核心领域流程：端到端主流程、上游配置与 4 路权益发放、智能选检与两阶段积分结算、预约履约与异常变更、双轨到检与报告解读、Benefit/Order/Appointment 三态状态机、体检代报销与积分报销
