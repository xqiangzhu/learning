R1｜失败 / 取消重约

预约失败、取消或超期释放 → 未过期则保留已支付主订单，回场景二重选分院；过期则熔断。

R2｜履约前退款

先级联取消预约 → 现金原路退款 → 退款成功回调后退还外部与镜像积分。

R3｜报销改卡重推

打款失败后原报销单修改银行卡，跳过人工复审直推财务；积分报销冻结状态保持。

预约异常分流

R1 重约回流预约失败 07、取消或超期释放；权益未过期 → 回场景二重选分院，已过期 → 终止。
R2 退款逆向履约前申请退款：级联取消预约 → 现金原路退 → 回调退积分。

R3 失败改卡重推

05 付款失败 → 用户在原单修改银行卡 → 跳过人工复审，直接再次推送财务。

关键边界

01 体检报销与预约互斥；02 复检报销凭独立权益可共存；积分报销仅员工本人。

系统协同与关键一致性控制

业务系统按同步查询、异步事件、机构回调与定时补偿协作。
HMSC 边端 / 核心订单预约权益报销核心查询同步；订单等 AFTER_COMMIT 经 MQ 推送，失败记录日志并补偿。
支付与积分平台核心积分福粒薪福通双边并发预冻结；支付退款异步回调；退款失败反查并进入补偿。
17+ 体检供应商锁单改期报告同步锁单，失败即时落标；回滚时反向取消释放号源；定时轮询 PDF。
TBDS 推荐服务问卷推荐历史报告推荐异常降级自主选购，不阻断主业务。
签章与 211 保险核心电子签章SFTP直赔门禁未完成即阻断；签章归档异步解耦并可补传。
